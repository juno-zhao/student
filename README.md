# 学生信息管理系统
## 项目简介
本项目是基于Python + easygui开发的简易学生信息管理系统，采用文本文件存储数据，无需数据库，使用弹窗图形界面完成操作。
功能包含密码登录验证、批量录入学生信息、按姓名查询学生信息。

## 文件清单
|文件名|作用|
| ---- | ---- |
|input_module.py|学生信息录入模块，完成学生信息采集写入文件|
|search_module.py|学生信息查询模块，读取文本文件按姓名检索|
|学生信息管理主程序.py|程序主入口，密码校验、功能菜单|
|门禁（密码设置）.py|初始化登录密码，生成密码.txt文件|
|密码.txt|存储登录密码，脚本自动生成|
|学生信息.txt|存储所有录入的学生数据，录入后自动生成|
